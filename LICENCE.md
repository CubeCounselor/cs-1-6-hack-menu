## 🧩 About

**Counter-Strike 1.6 Companion** is a curated list of Counter-Strike 1.6 open-source tools:

- **Overlays** — on-screen helpers, layout notes, overlay viewer, startpos switcher
- **Quality-of-Life Helpers** — config manager, skin catalog, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Practice Helpers
- Startpos Switcher — practice from any checkpoint
- Show Hitboxes — visualize player hitboxes
- Replay Notes — record and review match runs
- Playback Speed — adjust demo playback for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Skin Catalog — browse weapon skins, colors, trails
- Custom Config Notes — organize player configs
- overlay Overlay — improved overlay visibility

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any map
- Gravity Flip Control — manually switch gravity mid-game
- Jump Buffer Notes — chain complex maneuvers in practice
